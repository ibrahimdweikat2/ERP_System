# ERP Master Documentation

ابدأ من `00_MASTER_INDEX.md` ثم اقرأ الملفات بالترتيب الرقمي.

**Stack:** Laravel + MySQL + Laravel Database Queue + React + TypeScript + Tailwind CSS.

**Excluded:** Docker, Redis, PostgreSQL, Multi-Branch, Multi-Company, E-commerce.

الهدف: ERP احترافي لمحل واحد لبيع الأجهزة الكهربائية المنزلية في فلسطين، مع المخزون والـSerial Numbers والمبيعات والمشتريات والتقسيط والشيكات والمحاسبة والـVAT والتقارير والصلاحيات والتدقيق.
