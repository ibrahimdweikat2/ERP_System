# بيانات تجريبية لسنة كاملة — 2026

ملف `erp_demo_year_2026.sql` نسخة كاملة من قاعدة البيانات بعد توليد سنة تشغيل تجريبية،
من يناير حتى 22 سبتمبر 2026. البيانات وهمية بالكامل: الموردون والعملاء والأسعار مُختلقة.

## كيف تُولَّد البيانات

لم تُكتب الـ INSERT يدوياً. قاعدة البيانات محمية بـ triggers تمنع إدخال مستند مُرحَّل مباشرة،
ولهذا وُلِّدت البيانات عبر الأمر التالي، وهو يستدعي عمليات النظام الحقيقية نفسها التي تستدعيها الشاشات:

```bash
php artisan erp:demo-year
```

النتيجة أن كل قيد محاسبي وكل حركة مخزون وكل قسط وشيك مرّ بالتحققات والموافقات الفعلية.
**ميزان المراجعة متوازن: 2,759,585.9229 مديناً مقابل نفس المبلغ دائناً.**

## ما يمكن تتبّعه

- **دورة الشراء الكاملة:** أمر شراء ← موافقة ← إصدار ← استلام بأرقام تسلسلية ← فاتورة مورد ← دفعة.
- **التقسيط:** بيع بدفعة أولى 25% على 6 أقساط شهرية، مع أقساط مسدّدة وأخرى ما زالت مفتوحة لتظهر في تقرير الأعمار.
- **الشيكات:** استلام ← إيداع ← تحصيل، وحالة واحدة مرتجعة للمتابعة. لم تُسجَّل رسوم بنكية على الشيك المرتجع؛ تُضاف من شاشة الشيك عبر «تسجيل رسوم بنكية».
- **موافقة ائتمانية واحدة** على بيع بالتقسيط تجاوز حدود العميل.
- **الضريبة:** رمز ضريبي 16% للعرض فقط، ومعه سجلات ضريبة مدخلات ومخرجات.

## للاستيراد

```bash
mysql -h 127.0.0.1 -P 3307 -u <user> -p <database> < erp_demo_year_2026.sql
```

الملف يحذف الجداول ويعيد إنشاءها، فلا تستورده فوق قاعدة فيها بيانات حقيقية.

## تنبيهات

- **نسبة الضريبة 16% ورمزها `VAT16` بيانات عرض**، وليست إقراراً بالنسبة القانونية. راجع المحاسب قبل التشغيل الفعلي.
- **سياسة الأقساط** ضُبطت على `full_price_at_sale`، أي إثبات كامل سعر التقسيط عند البيع. هذا قرار محاسبي يخصّ صاحب العمل.
- **أسعار الصرف** شهرية وتقريبية (الدولار نحو 3.70 شيكل)، وهي للعرض فقط.
- النسخة الاحتياطية لما قبل التوليد محفوظة في `.runtime/demo-backups/`.
